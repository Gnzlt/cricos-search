# AGENTS.md

Guidance for AI coding agents working on this repository.

## Project

CRICOS Search is a public, unofficial, static website for searching courses on the Australian CRICOS register. It replaces the old ASP.NET search at cricos.education.gov.au. It is generic: it must not contain anything tied to a particular user or student.

Hosting is Cloudflare Pages (free tier). It serves `public/` as is, with no build step.

## Hard rules

- **No JS framework and no runtime dependencies.** Use plain HTML, CSS and native ES modules only. Do not add npm packages, bundlers, transpilers, CSS frameworks or CDN scripts. Dev tooling is limited to Node built-ins (`node:test`, `fetch`, `fs`).
- **No build step.** Whatever is in `public/` is what gets deployed. Do not introduce generated assets other than `public/data/*.json`.
- **Do not hand-edit generated files:** `public/data/`, `public/provider/`, `public/providers/`, `public/sitemap.xml` and `public/robots.txt`. They are generated by `scripts/fetch-data.mjs` (data) and `scripts/pages.mjs` (static HTML for SEO) and refreshed by CI. `public/og.png` is a hand-made social image (1200x630). The logo icons in `public/` (`logo.webp`, `icon-*.png`, `apple-touch-icon.png`, `favicon-32.png`) are cropped from `assets/logo-source.jpeg`.
- **Keep the footer attribution** to the data source (data.gov.au, CC BY 2.5 AU), the "Unofficial…" disclaimer, and the "Made by gnzlt.com" credit with its "Source code" link to the GitHub repo.
- **Content Security Policy** in `public/_headers` allows only `'self'`, plus Cloudflare Web Analytics (`static.cloudflareinsights.com` for the beacon script, `cloudflareinsights.com` for its reports). No inline scripts, inline `<style>` blocks, or other third-party origins. Attributes like `style="…"` on generated HTML are blocked by `style-src 'self'` too, so use classes.

## Layout

```
public/                 deployed as-is
  index.html            single HTML shell; views render into <main>
  css/styles.css        design tokens on :root, light theme only, mobile-first
  js/app.js             hash router and views (search, course, provider, compare, about)
  js/data.js            loads data/*.json and builds lookups
  js/search.js          pure filtering, sorting, URL state and CSV export (no DOM; unit tested)
  data/*.json           generated: meta, courses, providers, locations (columnar arrays)
  provider/<code>/      generated static pages, one per provider (what search engines index)
  providers/            generated provider index; sitemap.xml and robots.txt are generated too
  _headers              Cloudflare security and cache headers
scripts/
  fetch-data.mjs        CKAN API → download CSVs → build() → write public/data
  build.mjs             CSV → compact JSON; derives sector
  pages.mjs             pre-renders provider pages, provider index, sitemap and robots.txt
  csv.mjs               small RFC 4180 parser
test/                   node:test unit tests
.github/workflows/      test.yml (every push), refresh-data.yml (monthly cron + manual)
```

## Commands

```sh
npm test       # node --test test/
npm run data   # refresh public/data from data.gov.au (Node 22+)
npm start      # python3 http.server on http://localhost:8765
node scripts/fetch-data.mjs --from <dir>   # build from local CSVs (courses.csv, institutions.csv, locations.csv, course-locations.csv)
```

Run `npm test` before committing. For UI changes, serve `public/` locally and check the page in a browser at desktop width and at 375 px. There must be no horizontal scroll and no console errors.

## Data

- Source: the data.gov.au dataset `cricos` (Department of Education), updated monthly. Resource URLs are looked up by name through `package_show`. Never hardcode download URLs. Requests need a browser-like User-Agent (plain fetches get a 403).
- Only courses where `Expired === "No"` and that have at least one location are kept.
- Rows in `courses.json` are positional. The column order is in `courses.cols`. If you add or reorder columns, update `build.mjs`, `data.js` and the tests together.
- Sector is derived in `sectorOf()`, in this order:
  1. ELICOS (field 091501);
  2. VET (has a national code);
  3. Higher education;
  4. School;
  5. Other.
  
  Keep the About page text in sync if this changes.
- `fetch-data.mjs` refuses to write if the course count drops more than 20%. Do not weaken this guard.
- Fees are provider-declared and often out of date. The UI must keep saying so.

## SEO

The app uses hash routes, which search engines ignore, so indexable content comes from the static pages generated by `scripts/pages.mjs`. Each provider page has a unique title, description, canonical URL, Open Graph tags, `EducationalOrganization` JSON-LD and a table of its courses linking into the app. Keep the page count under Cloudflare Pages' 20,000-file limit, so do not generate one page per course. The canonical origin is `https://cricos.gnzlt.com` (override with `SITE_URL`).

## UI conventions

- **Routing:** hash routes `#/`, `#/course/<code>`, `#/provider/<code>`, `#/compare?c=a,b`, `#/about`. The landing intro (explanation, example chips, steps) shows only while no filter is active. Compare highlights the best cell per row via `bestOf()` in `search.js`. Search filters live in the hash query so every search can be shared. Add new filters to `DEFAULTS` in `search.js`.
- **Escaping:** HTML is built with template strings. Every data value goes through `esc()`.
- **localStorage:** used only for the compare shortlist, and always wrapped in try/catch. The page must work without it.
- **Design:** minimal, using the CRICOS palette (burgundy `#98012E` primary, navy `#0E4296` links, pale blue `#D9E6ED` tags) and the system font stack. The site is light only (`color-scheme: light`); change colours through the CSS variables on `:root`.
- **Accessibility:**
  - semantic elements;
  - 44 px touch targets;
  - visible focus;
  - `aria-live` result count;
  - WCAG AA contrast.

## Style

- Match the existing code: 2-space indent, double quotes, semicolons, small functions, and few comments that explain why rather than what.
- Use Australian English in user-facing text, and A$ amounts formatted with `Intl.NumberFormat("en-AU")`.

## Git

- Work on `main` with small, focused commits. Data refresh commits use the message `Data: CRICOS as at <YYYY-MM-DD>`.
- The repository is public. Never commit secrets or personal data.
